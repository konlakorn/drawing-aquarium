# ตู้ปลาของเรา

ตู้ปลาดิจิทัลสำหรับงานเด็ก เด็ก ๆ วาดปลาบนกระดาษขาว ถ่ายรูปด้วยมือถือ แล้วปลาจะว่ายเข้าไปในตู้บนจอใหญ่พร้อมชื่อเล่น

## ขั้นตอนในงาน

1. เปิดหน้า `/` บนทีวีหรือโปรเจกเตอร์ แบบเต็มจอ มุมขวาล่างมี QR code
2. เด็กวาดปลาบนกระดาษขาว ระบายสีเข้ม ๆ
3. ผู้ปกครองสแกน QR เปิดหน้า `/draw` แล้วถ่ายรูปปลาให้เห็นทั้งตัวในที่สว่าง
4. มือถือตัดพื้นกระดาษออกให้เอง (ทำในเครื่อง ไม่ส่งรูปต้นฉบับขึ้นเซิร์ฟเวอร์) เด็กเลือกว่าหัวปลาหันซ้ายหรือขวา ใส่ชื่อเล่นได้ แล้วกด "ปล่อยปลาลงตู้!"
5. ปลาว่ายเข้าตู้พร้อมฟองอากาศ ตู้มีปลาได้ 10 ตัว ตัวที่ 11 มาเมื่อไร ปลาตัวที่เก่าที่สุดจะค่อย ๆ ว่ายออกและจางหายไป

เสียงในตู้เริ่มแบบปิด กดปุ่มลำโพงมุมขวาบนเพื่อเปิด (เบราว์เซอร์ไม่ยอมให้เล่นเสียงเองถ้าไม่มีคนกด)

## รันบนเครื่อง

ต้องใช้ Node 22

```sh
npm install
npm start
```

เซิร์ฟเวอร์จะพิมพ์ลิงก์ตู้ปลา ลิงก์หน้าส่งปลา และลิงก์แอดมิน (`/admin?key=...`) ออกมา ถ้าเปิดตู้ด้วย `localhost` QR จะใช้ IP ของเครื่องในวง Wi-Fi แทน มือถือที่ต่อ Wi-Fi เดียวกันจึงสแกนได้เลย

ทดสอบ:

```sh
npm test
```

ใส่ปลาตัวอย่าง 12 ตัวให้เซิร์ฟเวอร์ที่รันอยู่ (ใช้เวลาราว 20 วินาที เพราะเซิร์ฟเวอร์รับได้ 1 ตัวต่อ 1.5 วินาทีต่อเครื่อง):

```sh
node scripts/seed.js 12 http://localhost:3000
```

## ค่าตั้ง (environment variables)

| ชื่อ | ค่าเริ่มต้น | ใช้ทำอะไร |
| --- | --- | --- |
| `PORT` | `3000` | พอร์ตของเว็บ |
| `PUBLIC_URL` | (ว่าง) | ที่อยู่เว็บจริง เช่น `https://my-aquarium.onrender.com` ใช้สร้าง QR ถ้าว่างจะเดาจากคำขอ |
| `ADMIN_KEY` | สุ่มใหม่ทุกครั้งที่เปิด | รหัสสำหรับหน้า `/admin` ใช้ลบปลาที่ไม่เหมาะสมและเพิ่มปลาเอง |
| `DATA_DIR` | `./data` | โฟลเดอร์เก็บรูปปลาและ `fish.json` |

## หน้าเว็บ

- `/` ตู้ปลาสำหรับจอใหญ่
- `/draw` หน้าส่งปลาบนมือถือ (ปลายทางของ QR)
- `/admin?key=...` ดูปลาในตู้ เอาออก และเพิ่มปลาเองได้ (รูปถ่ายบนกระดาษ หรือรูป PNG ที่ตัดพื้นไว้แล้ว) การเพิ่มจากหน้านี้ส่งต่อกันได้ทันทีไม่ต้องรอ

## ข้อควรรู้

- เก็บปลาไว้ในดิสก์สูงสุด 50 ตัวล่าสุด ตัวที่เก่ากว่านั้นถูกลบอัตโนมัติ
- **โฮสต์ฟรีที่ไม่มี persistent disk (เช่น Render แบบฟรี) จะลบปลาทั้งหมดทุกครั้งที่เซิร์ฟเวอร์รีสตาร์ตหรือ deploy ใหม่** ถ้าอยากเก็บไว้ ให้ต่อ disk แล้วตั้ง `DATA_DIR` ไปที่ disk นั้น
- Render แบบฟรีจะหลับเมื่อไม่มีคนใช้ เปิดหน้าตู้ทิ้งไว้ก่อนงานเริ่มสักครู่
- ถ้ามีคนลบปลาในตู้ผ่านหน้าแอดมิน ปลาตัวล่าสุดที่เคยว่ายออกไปจะกลับเข้ามาแทน เพื่อให้ตู้มีปลาครบ 10 ตัว
